# TokenWiser · 言镜：你的 AI 输入习惯教练

> 一面照出你输入习惯的镜子。只建议，不替换，只映照，不改变。
>
> 产品介绍 ≤1000 字，参赛材料与对外叙述共用此基线。

AI 大模型很贵，贵在输入端。个人开发者、重度 AI 用户、高校学生，每天都在向 ChatGPT、Claude、DeepSeek 输入指令。三笔看不见的账，就藏在这些输入里。

## 一、钱、效率、安全

**钱。** 模糊提问、整段贴日志、缺上下文，每轮悄悄多花几百 token，日积月累是不小的开销。平台账单只给总量，从不告诉你哪一轮在浪费。

**效率。** 指令模糊常引发两三轮来回拉扯，一句话能说清的事，拖成一段对话。

**安全。** API Key、身份证、手机号随手贴给 AI，泄漏了才发现。输入侧是数据安全的新暴露面，多数人毫无感知。

## 二、言镜：把输入习惯照出来

TokenWiser（言镜）是单机本地的 AI 输入习惯教练。你向大模型输入时，它自动检测六类坏习惯：大段日志粘贴、敏感信息泄漏、单条输入过长、冗余开场白、上下文或格式缺失、指令模糊。每一项都按对应模型的真实定价，量化成浪费的 token 与人民币金额，并给出可执行的改进建议。

它坚持"只建议，不替换"，永不改写你的内容。它像一面镜子，只把你看不见的输入习惯照出来，改不改由你决定。

## 三、三点不同

一是输入端诊断。现有工具要么只数 token，要么管输出侧用量统计，很少诊断输入习惯并量化归因，这是空白点。二是全模型精确计价。覆盖主流大模型，支持高峰低谷、缓存命中差异，成本按记录时刻回溯，统一人民币。三是隐私为先。分析全程本地完成、默认零上传；敏感字段加密存储、密钥出库；敏感片段落库前自动打码。

## 四、进展与目标

核心引擎已完成，17 项自动化测试全部通过：六类检测、精确计价、本地实时面板、一键安装、多 Agent 适配、敏感信息预警与阻断，代码已开源，进入小规模使用验证阶段。下一步是收集真实用户反馈，持续调优检测阈值。

言镜的目标很朴素：帮你用更少的 token 获得更好的回答，同时守住输入侧的隐私安全。小而精，先服务好一台机器上的自己。
