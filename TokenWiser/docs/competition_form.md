## 项目概述（约 430 字）

```
TokenWiser（言镜）是一款面向个人开发者与重度 AI 用户的本地输入习惯教练工具。它在你向大模型输入文字时自动检测六类不良习惯，包括大段日志粘贴、敏感信息泄漏、单条输入过长、冗余开场白、上下文或格式缺失、指令模糊，并按对应模型的真实定价量化每一轮浪费的 token 与人民币成本，给出改进建议。产品坚持只建议不替换，数据全部在本机处理，默认零上传，敏感字段加密后存储，隐私安全是默认设计而非附加功能。

用户群体主要是个人开发者、高频使用 AI 工具的用户与高校学生。他们为 AI 工具或 API 付费，希望减少 token 浪费、降低成本，并保护输入数据安全。

项目愿景是成为 AI 时代的输入侧效率与安全助手，帮助用户用更少的 token 获得更好的回答，同时降低敏感信息外泄风险。

目前同类工具多停留在输出侧，即统计 API 调用量或只做 token 计数，很少诊断输入端习惯并量化归因。TokenWiser 从输入端切入，结合精确计费与本地隐私架构形成差异化。
```

## 成果简介及转化需求（约 560 字，官网限 600）

```
本项目成果为「TokenWiser · 言镜」，一款单机本地的 AI 输入习惯教练工具。它在你向大模型输入文字时自动检测六类不良习惯：大段日志粘贴、敏感信息泄漏、单条输入过长、冗余开场白、上下文或格式缺失、指令模糊，并按对应模型的真实定价量化每轮浪费的 token 与人民币成本，给出改进建议。产品坚持只建议不替换，数据全部本机处理、默认零上传，敏感字段加密存储、敏感片段打码落库，隐私安全是默认设计而非附加功能。

目前核心引擎已完成开发并通过 17 项自动化测试：六类检测、覆盖主流模型的精确计价（含高峰低谷与缓存命中差异）、本地实时消耗面板、一键安装与多 Agent 适配、敏感信息识别与警告阻断。代码已开源，进入小规模使用验证阶段。

转化需求方面，当前以开源积累用户与口碑为主，暂不急于商业化。希望通过参赛获得更多真实用户反馈，验证需求与产品方向，并征集个人开发者、重度 AI 用户与高校学生的使用意见，反哺规则阈值与体验调优。后续可在产品成熟后探索订阅或捐赠模式，但商业化可行性尚未验证，需依据真实使用数据判断。
```
