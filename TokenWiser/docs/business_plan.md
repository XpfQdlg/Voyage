## 1. 执行摘要

- **项目一句话**：AI 大模型很贵，贵在输入端。TokenWiser · 言镜 是单机本地的 AI 输入习惯教练，在你向大模型输入时检测坏习惯，量化浪费的 token 与人民币成本，只给建议，不替改写。
- **市场痛点（三笔账）**：一是钱，模糊提问、整段贴日志、缺上下文，每轮多花几百 token，平台账单只给总量、不给单轮归因；二是效率，指令模糊引发 2-3 轮往返；三是安全，API Key、身份证、手机号随手贴给 AI，输入侧是数据安全的新暴露面。
- **产品与创新**：本地检测引擎覆盖六类坏习惯；按全量模型精确计价（含峰谷、缓存命中价），统一人民币；隐私优先，数据不出本机、落盘加密。核心创新是「输入端诊断」——现有工具管输出侧计数与监控，本项目管输入侧习惯与成本归因，是空白点。
- **当前进展（如实）**：核心引擎 v3 已跑通并开源，17 项自动化测试全部通过；已实现六类规则、全量模型计价、本地实时面板、一键安装、多 Agent 适配、落盘加密、敏感信息分类与打码、警告与阻断。进入小规模使用验证阶段。
- **商业**：现阶段免费开源，零收入、近零成本。商业化设想属「未来愿景」（见第 8、9 章），付费意愿未验证。
- **团队**：目前 1 人独立开发（网络空间安全专业 2025 级本科生，承担整体架构、检测引擎、产品设计），参赛成员按第 5 章分模块扩充。
- **一句话收尾**：小而精的输入侧效率与安全工具，先服务好一台机器上的自己。

## 2. 项目概述

### 2.1 项目背景：三笔看不见的账

个人用户正在为 AI 付三笔看不见的账。

1. **钱**：编码助手、ChatGPT、Claude、DeepSeek 进入日常，订阅按月付费、API 按 token 付费，token 就是钱。一次模糊提问、一次整段贴日志要多花几百 token，平台账单只给总量，不给单轮归因。
2. **效率**：指令模糊常引发 2-3 轮来回拉扯。说清目标、指定输出格式，能省下一轮往返。
3. **安全**：把密钥、身份证、日志贴给 AI 已成为常态，这是数据安全的新暴露面，多数人无感知。

### 2.2 产品定义

- 定位：言镜（TokenWiser），大模型输入习惯教练。检测不良输入习惯，量化代价，给出建议。
- 核心原则：**只建议，不替换**。永不自动改写用户内容。
- 交互：被动——严重度 high 才主动提示，不打断输入；主动——用户随时查看分析与代价。

### 2.3 产品功能

| 功能 | 说明 | 状态 |
|---|---|---|
| 习惯检测 | 六类规则：大段日志粘贴、疑似敏感信息、单条输入过大、冗余开场白、上下文/格式缺失、指令模糊 | 已实现 |
| 代价量化 | 按模型精确计价：全量模型表、峰谷、缓存命中差异，统一人民币，成本按记录时刻回溯 | 已实现 |
| 敏感信息预警 | 命中密钥、身份证、银行卡等时提示，可选警告或阻断；敏感片段落库前打码 | 已实现 |
| 习惯报告 | 周报：按周聚合各习惯出现次数与浪费 | 已实现 |
| 实时面板 | 本地 Web 面板：KPI、趋势、习惯分布、最近记录、安全事件卡片，10 秒刷新 | 已实现 |
| 多 Agent 适配 | Claude Code / Gemini / Cursor / Windsurf / Codex 统一 skill 形态 + 一键安装 | 已实现 |
| 落盘加密 | 敏感字段 AES-256-GCM 加密，密钥存于项目目录之外 | 已实现 |
| 浏览器扩展 | 覆盖网页端 AI 输入 | 【未来计划】 |

### 2.4 技术架构

- 核心引擎：纯 Python，零外部 API 依赖，`stdin → JSON` 契约，可被任意 Agent 调用。
- 检测管线：输入 → 剥离系统注入噪音 → 规则检测 → token 分割（tiktoken，未装则字符估算）→ 按模型计价。
- 持久化：本地 SQLite，敏感字段 AES-256-GCM 加密，密钥存于项目目录之外。
- 部署：skill 包 + hook 自动触发（行内提示，主机制）+ 本地面板（完整视图），statusline 为可选增强；`install.py` 一键安装，幂等。
- 隐私：分析全程本地完成，默认零上传。

### 2.5 技术创新点（写实，不夸大）

1. **输入端诊断**：现有工具管输出侧（API 用量监控、计费），本项目管输入侧（习惯诊断、单轮归因），是空白点。
2. **成本归因到习惯**：把每轮浪费 token 归因到具体习惯，给出可执行的节省金额，不只报总量。
3. **全量模型精确计费**：覆盖主流模型，支持峰谷定价、缓存命中价、人民币计价，成本随记录时刻回溯。
4. **系统注入剥离**：识别并剥离 Agent 运行时的系统注入内容，保证统计的是真实用户输入。
5. **隐私为先的架构**：数据不出本机、落盘加密、密钥出库、敏感片段打码存储。
6. **skill 形态多 Agent 移植**：一套规则包多 Agent 复用，用户迁移成本低。

## 3. 当前进展（现状，全部可验证）

### 3.1 已实现（v1.5 → v3）

- 六类习惯检测规则，含规则抑制与防误报（短句、跟进句、URL 跳过）。
- 敏感信息分类：凭据（API Key、Token、私钥、数据库连接串、统一社会信用代码、高熵片段）、隐私（手机号、身份证、银行卡，卡号须过 Luhn 校验、信用代码须过 GB32100 校验位）、联系（邮箱，medium）。支持警告/阻断，提示绝不回显敏感值。

## 4. 竞品与差异化

### 4.1 竞品类型

1. **token 计数器**：只数不诊，无习惯归因，无安全能力。
2. **API 监控 / 成本仪表盘**：管输出侧调用量，面向企业运维，个人不适用。
3. **提示词优化工具**：帮用户改提示词（替换式），与本项目"只建议不替换"理念相反，不量化代价。
4. **输入敏感信息过滤**：多为浏览器插件或 DLP 网关，只管脱敏，不管成本。

### 4.2 差异化定位

- 一句话：TokenWiser 是「输入侧的成本与安全提醒」，竞品是「输出侧的计数与监控」。
- 三个差异化：成本归因到习惯、隐私为先的本地架构、只建议不替换的产品哲学。

### 4.3 竞争壁垒（写实）

- 规则库与阈值基于真实会话数据迭代（误报从 12 降到 2）。
- 全量模型计价表与峰谷/缓存细分，是繁琐的"脏活"，复刻成本高。
- 隐私架构（加密、零上传）作为默认设计，而非后加功能。

## 7. 市场分析

### 7.1 市场背景与趋势

- AI 编码与办公工具渗透率上升，个人用户成为主要付费群体之一。
- 用户对 token 消耗与 API 成本的感知增强，出现追求性价比的"精打细算"人群。
- 数据安全意识提升，用户开始关注"我贴给 AI 的东西去了哪里"。

### 7.2 目标用户（按优先级）

1. 个人开发者：高频使用 AI 编码助手，对 token 敏感，有命令行习惯。
2. 重度 AI 用户：把大模型当日常生产力工具的学生、自媒体、文案、分析师。
3. 高校学生与实验室：算力/token 预算受限，早期用户与口碑来源。

### 7.3 需求痛点（对应解决方案）

| 痛点 | 现状 | TokenWiser 解决 |
|---|---|---|
| 多花冤枉钱 | 看不到单轮浪费 | 量化每轮浪费 token 与金额 |
| 输入效率低 | 模糊提问来回拉扯 | 提示缺上下文、指令模糊，省 1-2 轮往返 |
| 敏感信息泄漏 | 贴了 API Key 才发现 | 发送前预警（可配置警告/阻断） |
| 统计缺失 | 不知道自己一年花多少 | 本地面板 + 周报长期统计 |

### 7.4 市场规模（未来愿景，数字待调研，不编造）

- 口径：国内活跃 AI 工具个人用户数 × 对 token 成本敏感的人群占比 × 人均年可治理 token 消耗。
- 来源：【调研后填：平台公开活跃数据、艾瑞/IDC 个人 AI 应用报告，标注年份页码】。
- 结论：小而聚焦的利基市场，以工具口碑与开源社区为增长路径，不追求平台级规模。
